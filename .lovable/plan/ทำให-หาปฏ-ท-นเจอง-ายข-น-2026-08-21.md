# ทำให้หาปฏิทินเจอง่ายขึ้น

ตอนนี้ตารางปฏิทินมีอยู่แล้วที่เมนู "ปฏิทินงาน" (/planner) แต่ถูกดันลงไปอยู่ล่างสุด เพราะด้านบนมีแดชบอร์ดสถิติ, แจ้งเตือนอะไหล่ 30 วัน และรายการใบสั่งงานรออนุมัติซ้อนกันอยู่ก่อน จึงต้องเลื่อนลงไปนานกว่าจะเห็นช่องปฏิทิน

## สิ่งที่จะแก้

1. **ย้ายการ์ดปฏิทินขึ้นมาอยู่บนสุด** ถัดจากหัวเรื่องทันที ส่วนสถิติ / แจ้งเตือนอะไหล่ / ใบสั่งงานรออนุมัติ ย้ายลงไปไว้ด้านล่างปฏิทิน
2. **ย่อ-ขยายได้**: ทำแผงสถิติ, แจ้งเตือนอะไหล่, ใบสั่งงานรออนุมัติ ให้พับเก็บได้ (ค่าเริ่มต้นพับไว้ ยกเว้นใบสั่งงานรออนุมัติถ้ามีรายการค้าง จะเปิดไว้พร้อมตัวเลขแจ้งเตือน)
3. **เปลี่ยนชื่อเมนูบนแถบนำทาง** จาก "ปฏิทินงาน" เป็น "ปฏิทิน / แพลนเนอร์" พร้อมไอคอนปฏิทิน เพื่อให้สังเกตเห็นชัดขึ้น
4. **ปุ่มลัดจากหน้าแรก**: เพิ่มปุ่ม "เปิดปฏิทินแพลนเนอร์" ในหน้าค้นหา ใกล้ปุ่มเขียนใบสั่งงาน
5. ปรับปุ่มมุมมอง รายเดือน / รายสัปดาห์ / รายวัน ให้เด่นขึ้นบนจอเล็ก (แถวเดียว เต็มความกว้าง) เพื่อให้เห็นว่าเป็นปฏิทินสลับมุมมองได้

## รายละเอียดทางเทคนิค

- แก้ `src/routes/planner.tsx`: สลับลำดับ JSX ให้ Card ปฏิทินอยู่ก่อน `StatsPanel` / `PartsAlertPanel` / `PendingOrders` และครอบ 3 แผงนี้ด้วย Collapsible (shadcn) ที่มีอยู่แล้ว
- แก้ `src/routes/__root.tsx`: ปรับข้อความ + ไอคอนลิงก์ `/planner`
- แก้ `src/routes/index.tsx`: เพิ่มปุ่มลิงก์ไป `/planner`
- ไม่แตะฐานข้อมูลและตรรกะนัดหมายเดิม
