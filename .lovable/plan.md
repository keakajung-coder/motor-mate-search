# แผนเพิ่มสถานะงาน 3 ขั้นและขั้นตอนยืนยันนัดหมาย

## สิ่งที่จะปรับ
- เพิ่มตัวบอกสถานะแบบแถบด้านข้างพร้อมป้ายข้อความ 3 ขั้นในรายการงานและทุกมุมมองของแพลนเนอร์:
  - แดง: รอดำเนินการ
  - เหลือง: นัดหมายแล้ว / กำลังดำเนินการ
  - เขียว: เสร็จสิ้น
- แยกแถบสถานะออกจากสีขอบรถและสีพื้นช่างอย่างชัดเจน เพื่อให้รหัสสีทั้งสามระบบไม่ทับกัน
- ให้ผู้ใช้งานฝ่ายขายที่เข้าดูระบบเห็นรายการงานที่แอดมินอนุมัติแล้ว พร้อมวันที่นัดหมายปัจจุบัน
- เพิ่มปุ่ม “นัดหมายแล้ว” สำหรับฝ่ายขาย หลังโทรยืนยันลูกค้า โดยเลือก/แก้วันที่และเวลาได้ก่อนบันทึก
- เมื่อกดยืนยัน ระบบจะอัปเดตวันที่ เวลา และสถานะของทั้งใบสั่งงานกับรายการในแพลนเนอร์พร้อมกัน แล้วรีเฟรชปฏิทินทันที
- คงสิทธิ์อนุมัติ แก้ไขเชิงจัดการ ปิดงาน และลบงานไว้สำหรับแอดมินตามเดิม

## รายละเอียดทางเทคนิค
- ใช้สถานะเดิมของระบบและจัดกลุ่มเพื่อแสดงผล: `pending` = แดง, `approved`/`scheduled`/`in_progress` = เหลือง, `closed` = เขียว
- งานที่อนุมัติแล้วจะค้นหารายการนัดหมายด้วย `work_order_id`; การยืนยันนัดหมายจะอัปเดต `work_orders.visit_date/visit_time/status` และ `appointments.visit_date/visit_time/status`
- ทำตัวแสดงสถานะส่วนกลางเพื่อลดความคลาดเคลื่อนระหว่างการ์ดงาน รายการรายวัน และปฏิทินเดือน/สัปดาห์
- ตรวจการแสดงผลและการกดยืนยันทั้งหน้าจอขนาดเล็กและเดสก์ท็อป รวมถึงตรวจความถูกต้องของการสร้างแอป
