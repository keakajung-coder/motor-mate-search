# รวมรายชื่อผู้ขายและเซลล์

## สิ่งที่จะปรับ
- รวมข้อมูลเดิมจากประเภทผู้ขายและเซลล์ให้แสดงในส่วนเดียว โดยไม่ลบหรือย้ายข้อมูลในฐานข้อมูล
- ใช้ฟอร์มเพิ่มเพียงชุดเดียว: ชื่อ เบอร์โทร LINE ID และปุ่มเพิ่ม โดยไม่แสดงหรือรับข้อมูลบริษัท
- แสดงทุกรายการเป็นชื่อ เบอร์โทร และ LINE ID พร้อมสวิตช์แสดง/ซ่อนข้อมูลติดต่อรายแถว
- เพิ่มโหมดแก้ไขที่บันทึกชื่อ เบอร์โทร และ LINE ID ของรายการเดิม
- คงปุ่มลบพร้อมการยืนยันและสิทธิ์แอดมินตามเดิม

## รายละเอียดทางเทคนิค
- รายการใหม่จะบันทึกเข้ากลุ่มเดียว แต่รายการเดิมทั้งสองประเภทจะยังโหลดและแก้ไขได้ครบ
- การเปลี่ยนชื่อจะซิงก์ตัวเลือกผู้ขายเดิมเพื่อไม่ให้รายการซ้ำหรือสูญหาย
- ตรวจสอบหน้าจอขนาดมือถือและสถานะการสร้างแอปหลังแก้ไข
