## 1. แก้ไขข้อมูลได้ทุกช่อง

- **แท็บลูกค้า**: เพิ่มปุ่มแก้ไข (ดินสอ) → โหลด ชื่อ/เบอร์/ที่อยู่/หมายเหตุ ขึ้นฟอร์มด้านบน แล้วบันทึกทับ (ตอนนี้มีแค่เพิ่ม/ลบ)
- **แท็บยี่ห้อ**: เพิ่มปุ่มแก้ไขชื่อยี่ห้อ + โลโก้ (ตอนนี้มีแค่เพิ่ม/ลบ)
- ตรวจให้แท็บรุ่นเครื่อง / สินค้า / เครื่อง (S/N) แก้ได้ครบทุกช่องเช่นกัน

## 2. สถานที่ติดตั้งเครื่อง

เพิ่มฟิลด์ในตารางเครื่อง (S/N): `site_name` (ชื่อสถานที่/โรงงาน), `address_line` (ที่อยู่/แถว), `district` (อำเภอ/เขต), `province` (จังหวัด)

- ฟอร์ม S/N: ช่องกรอกครบ 4 ช่อง โดยจังหวัดเป็นแบบพิมพ์+เลือก (77 จังหวัด)
- หน้าค้นหา: แสดงสถานที่ติดตั้งในข้อมูลเครื่อง และค้นหาด้วยจังหวัด/เขตได้

## 3. คำนวณชั่วโมงการใช้งานอะไหล่

คำนวณอัตโนมัติจาก: `เปลี่ยนล่าสุด` + `ชม.ทำงาน/วัน` ของเครื่อง

```text
ชม.ใช้งานสะสม = (วันนี้ - วันเปลี่ยนล่าสุด) x ชม./วัน
ชม.คงเหลือ    = รอบเปลี่ยน - ชม.ใช้งานสะสม
วันครบกำหนด   = วันเปลี่ยนล่าสุด + (รอบเปลี่ยน / ชม.ต่อวัน) วัน
```

- แสดงในหน้าค้นหาและหน้าจัดการ: ชม.สะสม / ชม.คงเหลือ / % การใช้งาน (แถบสี เขียว-เหลือง-แดง) และป้าย "ถึงกำหนดเปลี่ยน" เมื่อเกิน
- ยังพิมพ์ทับค่าชั่วโมงเองได้ (ถ้ากรอกเอง ใช้ค่าที่กรอก)

## 4. ลดขนาดไฟล์ตอนแชร์ ≤ 1 MB

- สร้าง PDF ด้วยข้อความ/ตารางจริง (jsPDF text mode) แทนการแคปเป็นรูปทั้งหน้า → ไฟล์เล็กระดับ 50–200 KB
- ถ้ามีรูปอะไหล่ ย่อ/บีบเป็น JPEG คุณภาพต่ำก่อนใส่ และวนลดคุณภาพจนไฟล์ < 1 MB
- แสดงขนาดไฟล์ให้เห็นก่อนแชร์

## 5. แจ้งเตือนข้อมูลซ้ำ + ค้นหาในหน้าจัดการข้อมูล

- **S/N ซ้ำ**: เช็คตอนพิมพ์และตอนบันทึก → แจ้งเตือนสีแดง "S/N นี้มีอยู่แล้ว (ลูกค้า X)" พร้อมปุ่ม "ไปแก้ไขรายการเดิม" และกันบันทึกซ้ำ
- เช็คซ้ำแบบเดียวกันกับ Part Number (สินค้า), ชื่อลูกค้า, ยี่ห้อ, รุ่น
- **ช่องค้นหาในทุกแท็บของหน้าจัดการข้อมูล** (เครื่อง / ลูกค้า / สินค้า / ยี่ห้อ / รุ่น) กรองรายการทันทีขณะพิมพ์

## 6. นำเข้า / ส่งออก Excel • CSV • PDF

เพิ่มแท็บใหม่ **"นำเข้า / ส่งออก"** ในหน้าจัดการข้อมูล

- **ส่งออก**: เลือกตาราง (ลูกค้า / เครื่อง S/N / อะไหล่ในเครื่อง / สินค้า / ยี่ห้อ / รุ่น) + เลือกคอลัมน์ที่ต้องการ → ดาวน์โหลดเป็น `.xlsx` (หลายชีต), `.csv` (เปิดใน Google Sheets ได้) หรือ `.pdf`
- **นำเข้า**: อัปโหลด `.xlsx` / `.csv` → แสดงตัวอย่างข้อมูล + จับคู่คอลัมน์ → เลือก "เพิ่มใหม่" หรือ "อัปเดตทับของเดิม" (จับคู่ด้วย S/N หรือ Part Number) → แสดงสรุปว่าเพิ่ม/อัปเดต/ข้าม กี่รายการ
- มีปุ่มดาวน์โหลด "ไฟล์ตัวอย่าง (Template)" ของแต่ละตาราง

## รายละเอียดทางเทคนิค

- Migration: เพิ่มคอลัมน์ `site_name`, `address_line`, `district`, `province` ใน `machine_units`
- ไลบรารีใหม่: `xlsx` (SheetJS) สำหรับอ่าน/เขียน Excel; ใช้ `jspdf` + `jspdf-autotable` แทน html-to-image เพื่อลดขนาดไฟล์
- แยกโค้ดหน้า admin ที่ยาว 899 บรรทัด ออกเป็นคอมโพเนนต์ย่อยต่อแท็บ เพื่อให้แก้ไขต่อได้ง่าย
